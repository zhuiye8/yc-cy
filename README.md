# yc-cy

武汉数据智能研究院前端 demo。当前已实现首页、数据库查询、AI 分析页；产业链全景和空间态势保留可点击页面入口，后续由同事继续补齐。

## Run

```powershell
cd C:\work\yc-demo\demo
cmd /c pnpm install
cmd /c pnpm dev
```

Open `http://127.0.0.1:4173/`.

## Notes

- 客户原始设计稿目录 `首页二级页/` 不提交。
- PSD/JPG 参考图、截图和 debug 导出文件不提交。
- 页面运行所需的裁切素材保留在 `demo/assets/extracted/`。
